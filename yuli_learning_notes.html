Why split before scaling? Fit preprocessing only on training data to avoid leaking information from validation or test data.

from sklearn.preprocessing import StandardScaler

sc = StandardScaler()
X_train_scaled = sc.fit_transform(X_train)
X_test_scaled = sc.transform(X_test)

X_train and X_test must already be split. For cross-validation, put StandardScaler inside a Pipeline so it is fitted separately within each training fold.

Machine Learning A-Z Part 3 Classification

Logistic Regression

Logistic regression models the probability of a binary class using a sigmoid applied to a linear score. Unlike a perceptron, the model first produces a probability, not just a hard decision.

z = w₀ + w₁x₁ + w₂x₂ · p = 1 / (1 + exp(−z))
ŷ = 1 if p ≥ 0.5; otherwise ŷ = 0

At threshold 0.5, this decision is equivalent to checking whether z ≥ 0. Other thresholds may be appropriate.

Nearest-Neighbor Classification

Algorithm that, given an input, choose the class of the nearest data point to that input.

K-Nearest-Neighbor Classification

Algorithm that, given an input, choose the most common class out of the k nearest data points to that input.

KNeighborsClassifier default neighbors =5

Perceptron Learning Rule

Given data point (x, y), update each weight according to
wᵢ = wᵢ + α(actual value - estimate).xᵢ
wᵢ = wᵢ + α(y-hw(x)).xᵢ
α = learning rate -> how quick the weight gets updated
-> Only capable of learning linearly separable decision boundary

Maximum Margin Separator

A separating boundary that maximizes the margin to the nearest training points from the classes, rather than the distance between arbitrary pairs of points.

  • Support Vector Machine (SVM)
  • Kernel SVM

Looking for support vector regression? See SVR in the regression section below.

Support Vector Regression (SVR)

Loss Function

Function that expresses how poorly our hypothesis performs.

0-1 Loss Function

L(actual, predicted):
0 if actual = predicted
1 otherwise

L1 Loss Function

L(actual, predicted) = |actual - predicted|

L2 Loss Function

L(actual, predicted) = (actual - predicted)²
-> It penalises more rashly anything that is worse predicted

Overfitting

A model that fits too closely to a particular dataset and therefore may fail to generalize to future data.

Regularization

Penalizing hypotheses that are more complex to favor simpler, more general hypotheses
cost(h) = loss(h) + λcomplexity(h)

Holdout Cross-Validation

Use a training set to fit the model, a validation set (or cross-validation) to select models and tune hyperparameters, and a held-out test set for final evaluation. A simple train/test split is suitable when no tuning is performed on the test set.

K-Fold Cross Validation

Split the development data into k folds. Train k times, holding out one fold for validation each time and training on the remaining k − 1 folds. Average the validation scores; keep the final test set separate.

Regression Metrics · R² and Adjusted R²

R² = 1 − SS_res / SS_tot
SS_res = Σᵢ(yᵢ − ŷᵢ)² · SS_tot = Σᵢ(yᵢ − ȳ)²
ValueInterpretation (nonconstant target)
1Perfect predictions
0Same squared error as predicting the evaluation-set mean
Less than 0Worse than that mean baseline

Report performance on held-out data. R² is not an accuracy percentage, and its usual formula is undefined when the target is constant.

Adjusted R² = 1 − (1 − R²) × (n − 1) / (n − p − 1)

Here n is the sample count and p is the number of predictors, excluding the intercept. This standard formula assumes a regression model with an intercept and requires n > p + 1.

Adding predictors cannot decrease ordinary training R² for nested OLS fits on the same data. Adjusted R² penalizes extra predictors and may decrease; it does not replace validation.

Machine Learning / 3. Reinforcement Learning

3. Reinforcement Learning

An agent learns a policy through interaction with an environment, using numerical rewards to improve its future decisions. The agent can be software or a physical robot.

Wikipedia - Reinforcement Learning

Markov Decision Process

Model for decision-making, representing states, actions, and their rewards.

  • Set of states: S
  • Set of actions: ACTIONS (s)
  • Transition model: P(s'| s,a)
  • Reward Function: R(s,a,s')

Reading: Markov-Decision-Processes - University of California Berkeley

Q-Learning

Method for learning function Q(s,a), estimate of the value of performing action a in state s:

  • Optionally initialize Q(s, a) = 0 for every state-action pair.
  • every time we take an action a in state s and observe a reward r, we update:
Q(s, a) ← Q(s, a) + α [r + γ maxₐ′ Q(s′, a′) − Q(s, a)]
SymbolMeaning
αLearning rate
γDiscount factor for future rewards
rObserved reward
s′Next state
r + γ maxₐ′ Q(s′, a′)Temporal-difference target
Target − Q(s, a)Temporal-difference error

For a terminal next state, the bootstrap term is zero, so the target is just r. Initializing Q to zero is a common choice, not a requirement.

Wikipedia — Q-learning · The update moves the old estimate toward the reward plus the discounted best estimated value of the next state.

Greedy Decision-Making

When in state s, choose action a with higher Q(s,a)

Explore vs Exploit

  • Explore: try alternative actions to gather information about their rewards.
  • Exploit: choose the action with the highest current estimated value; this can miss better actions if estimates are incomplete.

Epsilon-greedy (ε-greedy)

  • set ε equal to how often we want to move randomly
  • With probability 1 − ε, choose an action with the highest current estimated value.
  • with probability ε, choose a random move

Function Approximation

Approximate Q(s, a) with a parameterized function (for example, a linear model or neural network), rather than storing a separate value for every state-action pair.

Deep Learning / 1. Artificial Neural Networks (ANN)

1. Artificial Neural Networks (ANN)

Tensorflow Neural Network Playground

The Ultimate Guide to Artificial Neural Networks (ANN)

Activation Function

A neuron first forms a weighted sum, then applies an activation function. The weighted sum itself is not the activation.

z = w₀ + w₁x₁ + w₂x₂ · a = φ(z)

w₀ is the bias term. Nonlinear activations let stacked layers learn nonlinear relationships; stacking only linear transformations still gives a linear transformation.

Wikipedia - Activation Function

Gradient Descent

Batch gradient descent computes the gradient of the training objective using the entire training set for each update.

  1. Initialize model parameters appropriately.
  2. Run a forward pass and calculate the loss.
  3. Compute parameter gradients with backpropagation.
  4. Update parameters in the negative-gradient direction.
θ ← θ − η ∇θ L(θ)

θ denotes trainable parameters and η the learning rate. A full-data update can be expensive; reducing the loss at every step is not guaranteed when the step size is too large.

Stochastic Gradient Descent

Strictly speaking, stochastic gradient descent estimates the gradient using one training example per update, typically with shuffled examples. Updates are cheaper and noisier than full-batch updates, but are not inherently “less accurate” as a training method.

In common software usage, “SGD” also includes mini-batch updates.

Mini-Batch Gradient Descent

Mini-batch gradient descent computes each update from a small group of training examples. This balances computational efficiency and gradient noise and works well with vectorized hardware.

L_batch = (1 / B) Σᵢ₌₁ᴮ ℓᵢ · θ ← θ − η ∇θ L_batch

B is the mini-batch size. One epoch is a full pass through the training data; an epoch usually contains many parameter updates.

Multilayer Neural Network

Artificial neural network with an input layer, an output layer, and at least one hidden layer.

Backpropagation

Backpropagation is an efficient way to calculate loss gradients with respect to the network parameters. It uses the chain rule; the optimizer—not backpropagation itself—decides how to update weights.

  1. Forward pass: compute intermediate activations, predictions, and loss.
  2. Backward pass: propagate derivatives from the output toward earlier layers.
  3. Optimizer step: update parameters using the computed gradients.

Deep Neural Networks

Neural network with multiple hidden layers.

Dropout

During training, dropout randomly sets selected activations to zero to reduce co-adaptation and help control overfitting. With inverted dropout, retained activations are scaled by 1 / (1 − p), where p is the drop probability. Dropout is disabled during standard inference.

Deep Learning / 2. Convolutional Neural Networks (CNN) / Computer Vision

2. Convolutional Neural Networks (CNN) / Computer Vision

Computational methods for analysing and understanding digital images. e.g.
- face recognition in social media to tag friends - autonomous driving to detect color of the traffic light - hand writing recognition

Pooling

Pooling summarizes local regions of a feature map, often reducing spatial resolution. It usually acts independently within each channel and has no learned weights.

Max-Pooling

Max pooling takes the largest value in each local window. For example, a 2 × 2 window containing [1, 3; 2, 4] produces 4. A stride of 2 downsamples each spatial dimension by a factor of 2 when dimensions divide evenly.

Convolutional Neural Network

A convolutional neural network uses learnable filters with local connectivity and shared weights to extract spatial features. A classification model can combine convolution, activation, pooling, and a prediction head.

Reading: Introduction to Convolution Neural Network

  • Input: a grid of pixel values with one or more channels.
  • Convolution: learned kernels scan local regions to produce feature maps.
  • Activation: a nonlinearity such as ReLU is applied to the features.
  • Feature hierarchy: earlier layers often detect simple local patterns; later layers can combine them into more complex patterns.
  • Pooling: optionally reduces spatial resolution.
  • Prediction head: flattening plus dense layers, or alternatives such as global average pooling, combines features into an output.

Training on MNIST: labeled digit images define a classification loss. Backpropagation computes gradients for convolutional kernels and other trainable weights; an optimizer updates them. Accuracy is an evaluation metric, not the usual differentiable training objective.

Feed-Forward Neural Network

Neural network that has connections only in one direction.
input -> network -> output

Deep Learning / 3. Recurrent Neural Network (RNN)

3. Recurrent Neural Network (RNN)

A recurrent neural network processes a sequence by updating a hidden state that carries information from earlier time steps. The recurrence is through the hidden state; the output need not be fed back as the next input.

hₜ = φ(Wₓxₜ + Wₕhₜ₋₁ + bₕ) · ŷₜ = g(Wᵧhₜ + bᵧ)

Applications include time-series forecasting, sequence labeling, and language modeling. LSTM and GRU are gated recurrent variants.
